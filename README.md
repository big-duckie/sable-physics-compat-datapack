# Sable: Physics Compat Datapack

This project is a datapack designed to replace **Sable: Physics Compat**. It provides compatibility layers and enhancements for Sable physics in the Minecraft modding ecosystem.

## Why Replace Create: Physics Compat?

The original *Create: Physics Compat* has issues. Broken JSON files can cause other mods to crash, and *Create: Physics Compat* is full of them. In addition, the deployment of a whole mod just to do the job of a datapack is a bit ridiculous.
